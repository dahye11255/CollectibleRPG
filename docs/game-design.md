## 1. 핵심 메커니즘

1. **자유 탐사와 확정 보상:** 해금된 Stage 1~5 중 하나를 골라 탐사한다. 완료하면 해당 스테이지 아이템 1개와 골드를 100% 지급한다.
2. **드롭 확률:** Common 50% / Uncommon 25% / Epic 15% / Ancient 9% / Supreme 1%
3. **Supreme Door-lock:** 현재 스테이지의 Supreme 장비를 **장착한 상태로** 해금을 요청하면 다음 스테이지가 열린다. 한 번 해금하면 영구 유지된다.
4. **100% 확정 합성:** 같은 스테이지·같은 등급 4개 → 상위 등급 1개.
5. **도감 완주 버프:** 스테이지별 C~S 5종을 모두 모은 뒤 보상을 받으면 탐사 시간이 영구 5% 단축된다. 5개 스테이지 모두 완주하면 최대 25%.
6. **단일 재화(골드):** 인벤토리 확장, 합성 수수료, 즉시 완료에 쓴다.

## 2. 아이템

- 이름은 `Stage X Grade` 형식이다 (예: Stage 1 Common, Stage 1 Supreme). 스테이지당 5종, 전체 25종.
- 장비 효과는 **전투력**뿐이다. 탐사 시간 단축 효과는 모든 등급에서 0%다.
- 전투력 (초안): 등급별 Common 10 / Uncommon 20 / Epic 40 / Ancient 80 / Supreme 160 × 스테이지 번호
- 장비 슬롯은 1개다. 회원가입 시 Stage 1 Common을 지급하고 자동 장착한다.

## 3. 스테이지

| 스테이지 | 기본 탐사 시간 (초안) | 필요 전투력 (초안) | 해금 조건 |
| --- | ---: | ---: | --- |
| 1 | 60초 | 10 | 기본 개방 |
| 2 | 120초 | 20 | Stage 1 Supreme 장착 |
| 3 | 180초 | 40 | Stage 2 Supreme 장착 |
| 4 | 240초 | 60 | Stage 3 Supreme 장착 |
| 5 | 300초 | 80 | Stage 4 Supreme 장착 |

- 스테이지별 최초 탐사를 완료하면 최초 탐사 보상(골드)을 1회 받을 수 있다.

## 4. 탐사 (Battle)

| 항목 | 규칙 |
| --- | --- |
| 시작 조건 | 장비 1개 장착, 전투력 ≥ 필요 전투력, 인벤토리 빈칸 1개 이상, 진행 중 탐사 없음, 해금된 스테이지 |
| 탐사 시간 | `ceil(기본 시간 × (1 − min(도감 버프 + 빙고 버프, 45%)))`. 탐사 시작 시점의 단축률을 적용하고 `battles.applied_reduction_rate`에 기록 |
| 종료 시각 | 시작 시 `end_time`을 계산해 DB에 저장한다. Node.js `setTimeout`을 쓰지 않는다 |
| 완료 | `NOW() >= end_time`일 때만 보상을 지급한다 |
| 시각 고정 | 탐사 중 장비를 교체·해제해도 이미 저장된 `end_time`은 바뀌지 않는다 |
| 즉시 완료 | 남은 시간에 비례한 골드를 내고 바로 완료한다 (초안: 남은 10초당 1골드, 올림) |
| 취소 | 진행 중인 탐사를 취소할 수 있다. 보상 없음 |
| 상태 전이 | IN_PROGRESS → COMPLETED / IN_PROGRESS → CANCELED |

## 5. 합성

- 같은 스테이지·같은 등급 4개 → 상위 등급 1개 (100%)
- 착용 중인 장비는 재료에서 자동으로 제외한다 (`id != equipped_item_id`).
- 수수료 (초안): Common→Uncommon 10, Uncommon→Epic 40, Epic→Ancient 160, Ancient→Supreme 640
- Supreme은 재료가 될 수 없다.

## 6. 도감

- 드롭과 합성 모두 획득으로 인정한다. 아이템을 소모하거나 팔아도 기록은 남는다.
- 보상: 골드 200과 탐사 시간 5% 영구 단축. 스테이지당 1회 (`codex_rewards` PK + 트랜잭션).

## 7. 도감 빙고

- 사용자마다 5×5 빙고판이 있고, 25종 아이템이 대상이다.
- 아이템 종류를 **처음** 얻으면(탐사 드롭, 합성, 가입 시작 아이템 모두) 서버가 빈칸 하나를 무작위로 골라 배치한다. 같은 종류를 다시 얻으면 등록하지 않는다.
- 배치된 위치는 영구 유지된다. 판매하거나 합성 재료로 써도 기록은 남는다.
- 가로 5, 세로 5, 대각선 2 = 최대 12빙고. 줄 판정은 서버가 조회 때마다 계산한다.
- 보상(사용자당 단계별 1회): 1빙고 10%, 3빙고 +5%, 5빙고 +5% 탐사 시간 단축. 빙고 최대 20%, 도감 25%와 합산 최대 45%.
- 보상 수령 이후 **시작하는** 탐사부터 적용한다. 진행 중 탐사의 종료 시각은 바뀌지 않는다.

## 8. 연구소

골드를 내고 연구 레벨을 올리면 효과가 영구로 적용된다. 비용 = 기본 비용 × 배수^현재레벨 (올림). 초기화하면 사용한 골드의 50%를 돌려받는다.

| 연구 | 레벨당 효과 | 최대 | 적용 위치 |
| --- | --- | --- | --- |
| 행운 | Common 확률 2%p를 상위 등급으로 이동 (UC 50%, EP 30%, A 15%, S 5% 비율) | Lv5: C40 / UC30 / EP18 / A10.5 / S1.5 | 탐사 드롭 |
| 연금술 | 합성 수수료 −5% (올림) | Lv5: −25% | 합성 |
| 교역 | 탐사 골드 +10% (내림) | Lv5: +50% | 탐사 완료 |
| 시간술 | 즉시 완료 비용 −10% | Lv5: −50% | 즉시 완료 |
| 자동 탐사 | 연속 탐사 예약 +1회 (기본 1회) | Lv4: 5회 | 탐사 시작 |

연속 탐사: 서버 타이머 없이, 회차별 종료 시각(시작 + 회차 × 탐사 시간)이 지난 회차를 사용자가 요청할 때 정산한다. 인벤토리가 가득 차면 정산을 멈춘다.

## 9. 골드와 인벤토리

- 획득: 탐사 완료, 최초 탐사 보상, 도감 보상, 아이템 판매
- 사용: 합성 수수료, 인벤토리 확장(+5칸, 100골드, 최대 50칸), 즉시 완료, 연구
- 인벤토리가 가득 차면 탐사를 시작할 수 없다.

## 10. 서버 원칙

- 드롭·확률·탐사 시간·전투력은 모두 서버가 계산한다. 시간 판단은 DB 시각 기준이다.
- 골드·아이템이 바뀌는 처리는 MySQL 트랜잭션으로 묶는다.
- 중복 지급은 상태 조건부 UPDATE(`affectedRows` 확인)와 UNIQUE 제약으로 막는다.
